Chapter 01

这个工具能做什么

一句话：把一个投资项目的散乱资料——财务 Excel、文字材料、扫描件 PDF——变成一份排版规整、符合评估机构固定范式的正式《投后评价报告》Word 文档。

使用者（资产评估机构）平时要反复给不同项目出这类报告，而报告的骨架和话术是固定的、内容随项目变。这个工具把固定的部分沉淀下来，把变动的部分交给 AI 按资料填写，最终渲染成可直接编辑的 Word 交评估师定稿。

它是怎么分工的 工具沉淀固定部分（章节结构、免责话术、格式排版、打分表模板）；AI 负责读资料、填能确定的事实（项目名、金额、日期、主体、财务数据、政策文号）；需要专业判断的地方留空并附话术提示（风险定档、成功度打分、评价结论）；最后渲染成 .docx，由评估师补齐判断后定稿。
换句话说，它替评估师干掉了重复的排版和抄写，把人的时间留给真正需要专业资质的判断。

它不替你做的事

  • 不替评估师下专业判断——风险打几档、成功度打多少分、最终结论倾向，一律留空等你填。
  • 不编造数据——资料里没有的金额和指标，它标「待补充」，绝不臆造。
  • 不改动排版样式——字体、字号、行距、页眉页脚都在 Word 模板里做死，代码只灌数据。
一句话记住定位 它是一台把资料变成合规初稿的流水线，不是替你签字的评估师。初稿由它产出，判断和落款永远是人的。

Chapter 02

两类报告怎么区分

这是开工前最重要的一步。范式判错，后面用的规范、模板、话术全错。工具支持两种范式——股权类和工程类，先分清你手上这单是哪一类。

对比项股权类工程类
评什么 对一家企业的股权投资（长期股权投资、被投公司经营） 一个工程建设项目本身（市政 / 建筑 / 改造 / 环保整治）
典型例子 收购、入股某科技公司；参股某类金融租赁公司 学生公寓建设；污水处理厂提标改造；商务区收购运营
章节骨架 四章制：项目基本情况 / 投资过程评价 / 投资效益评价 / 投后评价结论 七章制：项目概况 / 后评价工作情况 / 实施全过程评价 / 效果效益 / 环境社会效益 / 目标与可持续 / 结论与经验教训
编号体系 中文层级「一、（一）1、（1）」 阿拉伯多级「1 / 1.1 / 1.1.1」
正文字体 宋体 仿宋
免责声明 独立成页，4 段法律免责逐字固定 没有独立声明章节，靠正文「据委托方提供的资料」等资料来源限定语替代
判断口诀 评的是「对一家公司投了钱、看它经营得怎么样」= 股权类；
评的是「盖了 / 改了一个工程、看它建得怎么样、钱花得对不对」= 工程类。
拿不准时，翻资料里有没有 招投标 / 施工合同 / 竣工验收 / 工程结算——有这些，就是工程类。

两种产物层级

范式（股权 / 工程）之外，还要先判断你要做的是哪一层产物。这两个维度各自独立——先定层级，再在层级内部分股权还是工程。

对比项完整版投后评价报告后评价专项报告
是什么 几十页的正式报告，评估机构出具 10 页量级、报送上级的浓缩说明
输入什么 项目原始资料（财务 Excel / 文字材料 / 扫描件） 一份已做好的完整版报告 + 客户给的《专项报告》模板
走哪套流程 下面第 5 章的五步主流程 专项报告提炼流程（另见参考文档）
怎么选 客户给原始资料、要一份正式报告 → 走五步主流程；
客户给已完成的完整版报告加一份《专项报告》模板、要「提炼成模板样子」 → 走专项报告提炼流程。
Chapter 04

需要准备哪些输入资料

做完整版报告时，把项目的原始资料收齐丢给工具，主要有四类：

资料 A
Excel 财务数据

资产、利润、现金流等财务报表，工具按表读成结构化数据。

资料 B
文字材料 PDF

可复制文字的 PDF（可研、决议、说明等），直接抽取文字。

资料 C
扫描件 PDF

图片型、抽不出文字的 PDF，工具走 OCR 转成文字。

资料 D
独立图片

验收单 / 合同 / 许可证等单张图片，登记备用或读图取数。

Chapter 05

五步工作流程

拿到资料后，工具按下面五步把它变成 Word 初稿。理解每一步产出什么，你就知道自己在哪一步该介入。

1
识别范式
判断是股权类还是工程类 → 决定用哪套规范、哪个模板、哪套话术。
▼
2
读输入资料 → 结构化数据
把资料读成一份 data.json：项目名、金额、日期、主体、财务数据各归其位；扫描件走 OCR。
▼
3
匹配模板 + 填「能填的确定项」
挑对应模板，只填事实确定项：项目名、各环节金额、日期、各方主体、财务数据、政策文号，以及逐字固定的话术。
▼
4
需专业判断处 → 留空 + 附话术提示
风险定档、成功度打分、评价结论、数据缺失处一律留空，并附对应话术提示，绝不替评估师编。
▼
5
渲染 → 输出 .docx
模板 + 数据 + 插图渲染成成品 Word。评估师补齐判断、按 F9 更新目录后定稿。
▼
6
送审后收尾（可选）
客户返回带批注的稿 → 逐条处理批注 → 交付前自检，出干净定稿。

Chapter 06

四条核心原则（不可动摇）

这四条是工具的底线，也是这类报告能被采信的前提。使用中如果发现工具「越界」替你做了判断、或凭空补了数据，那一定是哪里出了错——这四条永远优先。

原则 01
AI 只填确定项，判断留空

风险定档、成功度打分、评价结论一律留空并附提示，绝不替评估师编分数、编结论。判断是人的专业职责。

原则 02
固定话术逐字不改

免责声明、固定原则句等属法律和规范措辞，原样搬、一字不动。（含项目事实的句子须先核实有据再用。）

原则 03
数据缺就标缺

资料里没有的金额、指标、日期，标注「待补充」，绝不臆造数字来把报告填满。

原则 04
排版 100% 照模板

字体、字号、行距、页眉页脚、封面全在 Word 模板里做死，代码只灌数据不碰样式，保真度等于那份真实报告。

一句话贯穿四条：能确定的，工具替你填全填准；不能确定的，工具替你留好、提醒你——但绝不替你编。

Chapter 07

常见问题与关键提醒

这些是实操中最容易踩的坑，出稿前对照过一遍，能省掉大部分返工。

  1. 工程类没有独立免责声明。别把股权类那 4 段免责声明搬到工程类报告里——工程类靠正文「据委托方提供的资料 / 据委托方反馈 / 评价人员现场查勘」这类资料来源限定语承担免责功能。
  2. 成功度打分表按项目性质选。新建市政 / 环保工程（如污水处理厂提标改造）→ 用工程细表 20 指标；收购、存量或股权投资 → 用 7～8 维度表；需多专家评审的复杂设备投资 → 用专家团加权 15 子指标。别一套表套所有项目。
  3. 国资项目用官方五档。属地方国资体系的项目，成功度结论统一用官方五档：优（≥90）/ 良〔80,90）/ 中〔70,80）/ 低〔60,70）/ 差（<60），别换别的分档口径。
  4. 环保整改类工程效益按「达到环保要求」定性写。污水处理厂提标改造、污水零直排、管网改造这类工程无直接财务收益、改造前后数据常缺失——不补数据、不编数字，效益章按「完成改造、满足环保排放要求、取得排水许可、验收合格」定性写，以许可证和验收文件作达标实证。
  5. 目录不会自动更新。Word 里的目录是「域」，程序生成后页码是空的。评估师打开 Word 后需全选按 F9 更新域，交付前务必确认目录页码正确。
介入时机速查
你（评估师）主要在这几处出手：
  • 第 4 步所有留空占位处：补判断
  • 成功度打分表：定分值与等级
  • 评价结论：定最终倾向
  • 目录：按 F9 更新页码
交付前最后一眼
出稿前对照确认：
  • 占位符是否都已补齐
  • 数字是否与原始资料一致
  • 缺失项是否如实标「待补充」
  • 目录页码是否正确
最后叮嘱 工具产出的是初稿，不是终稿。所有专业判断、最终结论和签字，始终由评估师本人完成——这既是合规要求，也是这份报告价值的所在。
