# 示例：污水处理厂提标改造工程 投后评价报告

这是一套**完全虚构**的工程类投后评价示例，用来演示本工具「data.json + Word 模板 + 渲染脚本」这条链怎么跑通。clone 下来即可一条命令生成一份样片报告。

> ⚠️ **数据全部虚构，仅供演示。** 项目名、公司名、金额、文号、日期、评分等一切信息均为编造（统一带「示例/样例」字样），不指向任何真实客户或项目。请勿当作真实报告使用。

## 这个示例是什么

- **范式**：工程类（七章制），套用 `templates/工程类模板.docx`。
- **项目性质**：环保整改类工程（污水处理厂提标改造），无直接财务回报——正好用来示范工具的两条核心姿势：
  1. **效益章定性写**：环保整改类工程效益按「达到环保排放要求」定性评价，用排水许可 + 验收合格文件作达标实证，不硬凑财务收益数字。
  2. **专业判断处留占位**：成功度分值/等级、成功度总分、评价结论这些需评估师下判断的地方，填 `【待评估师判断：…】` 占位文案，工具不替评估师编分数。

## 目录里有什么

```
examples/示例污水处理厂工程/
├── data.json                          虚构工程项目的完整渲染数据（覆盖模板全部变量/循环）
├── README.md                          本说明
└── 示例污水处理厂工程投后评价报告.docx        跑出来的样片成品（证明这条链能跑通）
```

## 怎么跑

在工具根目录下执行（`examples/示例污水处理厂工程/data.json` 里 `report_type` 已设为 `engineering`，脚本据此自动选工程类模板）：

```bash
python3 scripts/build_report.py examples/示例污水处理厂工程/data.json examples/示例污水处理厂工程/示例污水处理厂工程投后评价报告.docx
```

依赖：`docxtpl`（含 jinja2）、`python-docx`。

## 跑出来是什么

一份排版好的 `.docx` 投后评价报告（约 170 段、4 张表格）：封面抬头、项目概况、后评价工作情况、实施全过程、效果效益评价、环境社会效益、目标与可持续、结论与经验教训、对策建议、附件清单一应俱全；投资构成表、决策链表、投资控制对比表、成功度指标表四张循环表均由 `data.json` 的列表数据填充。

打开成品后：
- 按 F9 更新目录域（页码才正确）；
- 检索所有 `【待评估师判断：…】`，由评估师补齐成功度打分、等级、评价结论。

## data.json 关键结构

- 顶层 `report_type: "engineering"` —— 脚本据此选工程类模板（必填）。
- 标量变量：项目名称 / 委托方 / 各章文字评价等，逐一对应模板里的 `{{变量}}`。
- 循环列表（对应模板 `{%tr for%}` / `{%p for%}`）：
  - `投资构成表`（项目/数额/单位）
  - `决策链表`（时间/文件/内容）
  - `投资控制表`（环节/可研预估/投后分析/差额）
  - `成功度指标`（指标/重要性/权重/分值/等级/实施成果，其中分值/等级为待判断占位）
  - `对策建议` / `附件清单`（字符串列表）
